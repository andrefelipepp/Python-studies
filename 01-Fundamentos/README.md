# O que é Python?

Python é uma linguagem de programação popular. Foi criado por Guido van Rossum, e lançado em 1991.

É utilizado para:

- desenvolvimento web (servidor-lado),
- desenvolvimento de software,
- matemática,
- script do sistema.

## O que o Python pode fazer?

- Python pode ser usado em um servidor para criar aplicações web.
- Python pode ser usado em conjunto de software para criar fluxos de trabalho.
- Python pode se conectar a sistemas de banco de dados. Também pode ler e modificar arquivos.
- Python pode ser usado para lidar com big data e realizar matemática complexa.
- Python pode ser usado para prototipagem rápida, ou para desenvolvimento de software pronto para produção.

## Por que Python?

- Python funciona em diferentes plataformas (Windows, Mac, Linux, Raspberry Pi, etc).
- Python tem uma sintaxe simples semelhante à língua inglesa.
- Python tem sintaxe que permite que os desenvolvedores escrevam programas com menos linhas do que algumas outras linguagens de programação.
- Python é executado em um sistema de intérprete, o que significa que o código pode ser executado assim que é escrito. Isso significa que a prototipagem pode ser muito rápida.
- Python pode ser tratado de uma forma processual, de uma forma orientada a objetos ou de uma forma funcional.

## É bom saber

- A versão principal mais recente do Python é o Python 3, que usaremos neste tutorial.
- Neste tutorial Python será escrito em um editor de texto. É possível escrever Python em um Ambiente de Desenvolvimento Integrado, como Thonny, Pycharm, Netbeans ou Eclipse, que são particularmente úteis ao gerenciar coleções maiores de arquivos Python.

## Python Syntax em comparação com outras linguagens de programação

- Python foi projetado para legibilidade, e tem algumas semelhanças com a língua inglesa com influência da matemática.
- Python usa novas linhas para completar um comando, em oposição a outras linguagens de programação que geralmente usam pontos e vírgulas ou parênteses.
- Python depende de recuo, usando espaço em branco, para definir o escopo; como o escopo de loops, funções e classes. Outras linguagens de programação geralmente usam suportes encaracolados para esse fim.
